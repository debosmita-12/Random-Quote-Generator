#  Random Quote Generator

A modern, responsive **Random Quote Generator** built with **React**, **JavaScript**, and **CSS**. The application displays inspirational quotes, allows users to generate random quotes, search by quote text or author, and filter quotes by category—all without requiring a backend.

---

##  Live Features

-  Displays a random quote on page load
-  Generates a new random quote with a button click
-  Prevents consecutive duplicate quotes
-  Search quotes by text or author
-  Filter quotes by category
-  Fully responsive design
-  Modern Glassmorphism-inspired UI
-  Built using reusable React components
-  Uses React Hooks (`useState`, `useEffect`)
-  Local data source (No backend required)

##  Installation

Clone the repository

```bash
git clone https://github.com/debosmita-12/Random-Quote-Generator.git
```

Navigate to the project folder

```bash
cd quote-generator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
